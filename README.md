🍈 Melon Tweaks v2.1

Melon Tweaks is a Windows batch utility created by siersciuch.

The project provides a simple menu for Windows maintenance, diagnostics, cleaning and selected system tweaks.

✨ Features
🇬🇧 English / 🇵🇱 Polish language selection
🔐 Automatic administrator privilege check
💾 Drive information
🔍 CHKDSK
🛠️ DISM repair tools
🛡️ SFC system file checker
🧹 Temporary files cleaning
🌐 Network tools
📡 DNS cache cleaning
🔄 Winsock reset
⚡ Power plan management
💤 Hibernation management
🖥️ CPU / RAM / GPU information
📋 Startup programs
⚙️ Windows services information
🔧 Windows maintenance tools
🧪 K-Tweaks / Beta support
🚀 How to use
Download the latest .bat file from the Releases section.
Run the file.
If Windows asks for administrator permissions, click Yes.
Select your language:
1 — English
2 — Polski
Choose an option from the main menu.
⚠️ Warning

Some functions require administrator privileges.

Some operations, such as resetting network components or changing power settings, may require a Windows restart.

The cleaning functions are designed to remove temporary/cache files only. Always make sure you understand an option before using it.

📦 Requirements
Windows 10 / Windows 11
Administrator privileges for some functions
PowerShell
